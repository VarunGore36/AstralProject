What is Astral

Most backtests answer the wrong question.

They ask would this idea have made money — on data nobody can inspect, with fills nobody can verify, under assumptions nobody wrote down. A quoted spread is treated as an executable opportunity. A paper result is presented as performance.

Astral asks a smaller, harder question instead: can we measure whether an apparent opportunity is actually executable — after fees, slippage, latency, liquidity, market impact, execution constraints, realistic fills and capital constraints?

It answers with a continuously-collected, provenance-tracked market-data corpus, a deterministic replay engine, and an honest execution-cost harness. Every result carries its dataset hash, its assumptions, and a reproduction command. A rigorous “this has no edge” is a successful result here.

Architecture

A pipeline you can audit at every joint.

Raw venue bytes in. Reproducible claims out. Nothing in between is a black box.

Lossless capture

Raw frames written to compressed, content-addressed chunks with capture timestamps and a SHA-256 integrity index. Binance depth diffs, partial books, trades, book ticker, funding and liquidations — plus Bybit order books on spot and perp. Read-to-stored p99 around a millisecond on live feeds (per-venue table and methodology in the README verification record — live-measured, not reference hardware). Drops and gaps are recorded as data, never absorbed silently.

Checked reconstruction

L2 books rebuilt from diffs on a snapshot bootstrap, with venue update-ID continuity enforced. A broken book rejects events until a new snapshot — it never silently resumes. The live book updates as frames arrive at single-digit-microsecond p50 (Binance p99 68µs, Bybit p99 32µs, live-measured).

Deterministic replay

Same capture replayed twice: identical signal hashes, verified live — over book diffs, trade prints (bundles expanded per print), and top-of-book. Cross-machine proof awaits a second machine — the procedure is written (docs/cross-machine-repro.md), stated, not assumed.

Third venue connected: 33 genuine matches and 35 tickers captured live. No order book exists publicly, and the shared sequence admits no strict rule — so both report unchecked, honestly.

Full suite, lints, panic-surface scan, and a line-by-line review of every production path in the measurement pipeline. Three bugs fixed same-day. Thirteen findings ranked and left open. Full detail in the audit doc.

145 tests, all green

17 book · 16 normalize · 86 record · 10 replay · 15 types, plus one overflow guard each at three sites. Zero ignored, zero failed.

Zero clippy warnings

Panic surface swept

Every production unwrap inspected. All live in test modules except one guard-proven framing read — flagged as hygiene, not a bug.

Fixed same-day

Fixed · overflow

Continuity arithmetic panicked at u64::MAX

Live tracker, offline audit, and reconstructor computed previous + 1 on venue-supplied IDs — exit 101 in debug on a hostile payload. Now checked_add with regression tests at all three sites.

Fixed · soak behavior

Reconnect backoff manufactured 30s holes

Waits doubled without reset across a long soak, while a failed attempt already ends the capture. Now a fixed 250ms wait; dead constant removed.

Fixed · audit gap

check trusted the manifest it audited

Replay and normalize enforced the frame count; the soak's judge did not, and never printed stop_reason. Now reports manifest_mismatch as unhealthy.

Closed since the audit

Closed · overflow

Continuity arithmetic at u64::MAX

Three previous + 1 sites panicked in debug on hostile IDs — proven exit 101. Now checked_add with a regression test each.

Closed · backoff

Reconnect waits no longer accumulate

Waits doubled toward 30s across long soaks for no benefit. Now a fixed 250ms — a failed attempt already ends the capture.

Closed · manifest trust

check verifies frame counts

Replay and normalize enforced the manifest; the soak's judge did not. Now reports manifest_mismatch as unhealthy, plus stop_reason.

Closed · schema gate

Captures declare versions; tools enforce them

check, normalize, replay, and reconstruct refuse a newer schema_version — one gate test per reader.

Closed · book errors

Failed live-book applies are counted

Bad levels no longer vanish: every capture prints updates and errors side by side, covered by a hostile-diff test.

Closed · output contracts

All seven CLI formats pinned

Every report renders through a golden-tested library function — including the frames and verdict lines the soak scripts parse.

Closed · decimal range

Parquet columns can't overflow silently

Hostile 13-digit values parsed fine but never fit Decimal128(20,8). All three validators reject out-of-range batches whole.

Closed · sides & prints

Trade sides canonical, corrupt prints skipped

Side labels fail closed to Buy/Sell-or-unknown; non-positive prints can never fill. Fills need real counterparties.

Closed · gap accounting

reconstruct counts connection gaps

Markers classified on the walk — connection-type counted, sequence-type left to the book's own break — and undecodable markers abort like everywhere else.

Principles

The epistemics are the product.

Reproducibility

Same inputs, same code, same result — on any machine. Every claim carries a reproduction command.

Realistic execution

No fill without a trade print through your price. No quoted spread presented as an opportunity.

Provenance

Every byte traced to its venue, its capture, its schema version. Quality tiers, not blind trust.

No fake profitability

Backtests are labelled backtests. Paper is not live. Optimistic models are marked unrealistic in the output itself.

Transparent assumptions

Fees, slippage, latency, capital, execution model — on the chart, not in a footnote.

Negative results count

“No edge” is a first-class, publishable finding. Refutation is the mechanism that makes positive claims worth trusting.

Roadmap

Gates with kill criteria, not a feature wishlist.

Each stage must earn the next one with evidence. If a gate fails, the project stops or pivots — that outcome is designed in.
